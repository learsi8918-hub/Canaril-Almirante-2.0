# Canary Control Pro

Sistema profissional e editável para gestão de criatórios de canários.

## V13.1
- Primeiro acesso com cadastro do criador e criação de senha.
- Logo escolhida pelo usuário.
- Banco SQLite local.
- Plantel, reprodução, ovos, filhotes, baixas, saúde e retrocruzamento preparados.
- Catálogo FOB local em `assets/catalogo_fob.csv`.
- Serviços de backup, exportação e notificações preparados.

## Importante
O aplicativo não possui dados de um canaril específico. O plantel começa vazio e o criador cadastra suas próprias informações.

## Gerar APK
Use o workflow em `.github/workflows/build_app.yml` com Flutter/Android SDK configurados.
