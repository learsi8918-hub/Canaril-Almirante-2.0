# Canary Control Pro V14

Aplicativo Flutter profissional e genérico para gestão de canários. A instalação começa sem plantel pré-cadastrado e permite configurar o canaril.

## V14
- Identidade do criador/canaril
- Logo e paleta automática extraída da logo
- SQLite como banco local
- Plantel com anilha permanente, gaiola, sexo, FOB, origem, foto e observações
- Reprodução com monogamia, bigamia e poligamia
- Relação independente macho/fêmea/gaiola/data
- Ovos por registro e atribuição aos pais
- Datas de ovoscopia, nascimento, anilhamento e desmame
- Lembretes locais
- Relatórios de fertilidade
- Baixa sem apagar histórico
- Saúde e estrutura de genealogia/retrocruzamento preparadas no banco
- Catálogo FOB importado como asset para seleção
- Backup JSON
- GitHub Actions para APK debug e Android SDK 36

> A V14 foi estruturada para crescer para milhares de aves. Recursos avançados de genealogia, saúde, retrocruzamento e exportações detalhadas permanecem modelados no SQLite para expansão das telas.
